# Corporate.bd

A frontend demo website inspired by **Corporate.bd**, an enterprise digital solutions company in Bangladesh.

This project is being developed as part of my **DIPTI MERN Course** to practice and demonstrate modern frontend development using **HTML, CSS, Tailwind CSS, JavaScript, and DOM manipulation**.

> **Note:** This is an educational/demo project and is not the official Corporate.bd website.

## 🎯 Project Objective

The main objective of this project is to recreate the look, structure, and user experience of a real corporate website while practicing:

* Semantic HTML
* CSS styling and layouts
* Tailwind CSS
* Responsive web design
* JavaScript
* DOM manipulation
* Form validation
* Interactive UI components

## 🏢 About the Reference Website

Corporate.bd provides business-focused digital and technology services in Bangladesh, including digital infrastructure, web development, managed IT, legal compliance, and SEO/digital marketing services.

This project takes inspiration from the structure and visual presentation of the official website while implementing the frontend independently for learning purposes.

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will then be available through the local Vite development server.
